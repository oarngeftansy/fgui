## Self-review

- Public build/review payloads contain no artifact path; generated bytes are exposed only through
  authenticated owner-bound routes.
- Approval checks current warnings, generation, selection fingerprint, review approvability, and artifact
  identity. Rejection and supersession keep download permanently closed.
- Every artifact use rechecks lexical expected root, directory/file identity, Windows reparse/symlink state,
  exact size, and SHA-256 through a stable open handle.
- Build/review failures use fresh allow-listed diagnostics; private exceptions and raw evidence are not
  serialized. Failed output directories are best-effort removed and never become downloadable records.
- Regeneration allocates a fresh candidate/build ID and incremented generation, reruns Task 1 from the
  immutable committed selection, and invalidates the previous candidate before execution.

## Deep User Audit: plugin Writer backend workflow

**Real Job**

Turn the current committed Figma selection into a trustworthy FairyGUI 6.1.4 project, inspect the exact
candidate, correct supported issues, and download only the explicitly approved generation.

**Top Pain Points**

1. The HTTP create/regenerate handlers execute the Writer synchronously before returning their `202`, so a
   slow real selection can look stalled and cannot expose intermediate polling progress to the plugin.
   改进：move leased execution onto the existing background-worker pattern while retaining the same candidate
   state machine and heartbeat.
   验收：POST returns the persisted `converting` candidate promptly; polling observes only legal monotonic stages
   and reaches `awaiting_review` or `failed` without keeping the POST connection open.

2. Safe adjustment storage and regeneration exist, but this backend batch deliberately does not add the
   frontend controls; a daily plugin user cannot invoke them until the approved client task lands.
   改进：implement the strict TypeScript client and state-driven review UI against these routes without adding a
   parallel contract.
   验收：the plugin can select an actionable issue, choose only an allowed strategy, regenerate to generation +1,
   and cannot act on the invalidated prior candidate.

**Immediate Next Fixes**

- Keep the short-basetemp Windows command in CI/developer documentation for Writer integration tests.
- Surface the static failure code and retry action verbatim in the forthcoming plugin client.

**Larger Bets**

- Add cancellable background execution and bounded persisted stage history for long-running conversions.
