# Memory — 偏好与约定

- 用户要求交付前必须自检，不能只声明“应该能运行”。
- “村庄升阶”只是一份回归样例；产品必须是可扩展的通用 Figma → FairyGUI 工具，禁止针对该页面硬编码。
- 主流程是 `Figma → UIR → FGUI Plan → 新建 FairyGUI 工程/XML → 校验 → ZIP`。
- 新建工程模式不得要求用户先提供或扫描已有 FairyGUI 工程。
- 扫描已有 FairyGUI 工程仅属于“更新已有工程、复用公共资源或绑定既有组件”的可选模式。
- 转换不能静默丢失视觉或行为；无法可靠表达的能力必须明确降级或 fail closed，并给出可操作诊断。
- 通用组件映射文件保存逻辑名称和语义，不保存某个工程的真实 package/component ID。
