# Figma 插件 ZIP 交付流程设计

## 目标

将用户交互收口到标准 Figma 插件中。UX 设计师不再打开 Web Console、记忆地址或输入配对码。用户在插件内提交当前 Figma 选择和 FairyGUI 工程 ZIP，由公司内网服务转换并返回更新后的工程 ZIP。

## 范围

本次交付包含：

1. 可安装的 Figma 插件包。
2. 公司内网转换服务部署包。
3. 面向设计师的插件安装与使用说明。
4. 面向管理员的服务部署与配置说明。

本次不包含：

- 独立 Web Console 操作页面。
- 配对码、设备绑定或浏览器跳转。
- 直接覆盖用户电脑上的 FairyGUI 工程。
- Windows 本地 Agent。

## 架构

Figma 插件是唯一用户入口，负责读取当前选择、采集必要的图层与资源数据、接收工程 ZIP、上传转换任务、展示检查结果和下载产物。

公司内网服务负责 ZIP 解包与安全校验、Figma 选择转换、FairyGUI 工程变更、结构与资源检查、重新打包和临时数据清理。服务地址由插件构建或管理配置确定，不暴露给日常用户输入。

## 用户流程

### 1. 确认 Figma 选择

插件打开后立即读取当前选择，展示顶层名称和图层数。当选择为空时，后续操作禁用，并提示“请先选择要转换的画面”。用户可刷新选择，无需关闭插件。

### 2. 上传 FairyGUI 工程

用户拖入或选择一个 `.zip` 文件。插件在上传前检查扩展名、文件大小和可读性；服务端负责权威的 ZIP 安全检查、目录结构检查和 FairyGUI 工程识别。

### 3. 转换与检查

用户点击“开始转换”后，插件依次显示：正在上传、正在解析、正在转换、正在检查、正在打包。重复点击不得创建重复任务。

检查结果按三级展示：

- 成功：可下载。
- 警告：可下载，但需向用户解释影响。
- 错误：禁止下载错误产物，明确指出需要修正的内容。

### 4. 下载更新工程

成功后插件展示变更摘要、警告和错误数量，并提供“下载更新后的工程 ZIP”。文件名格式为 `项目名-Figma更新-YYYYMMDD-HHmm.zip`。原 ZIP 不被修改。

## 数据与安全

- 插件仅上传当前选择及转换必需资源，不上传整个 Figma 文件。
- 服务只接受配置的 Figma 插件来源，不使用全开放 CORS。
- ZIP 解包需防止路径穿越、压缩炸弹、超大单文件和总体积超限。
- 上传的工程、Figma 选择数据和产物按管理策略定时清理，不作为长期存储。
- 错误信息不向设计师显示服务端路径、凭据或堆栈。

## 错误处理

用户提示必须区分：未选择 Figma 内容、不支持的文件、ZIP 损坏、非 FairyGUI 工程、文件超限、无法连接内网服务、转换失败和打包失败。不得将网络异常显示为“配对码错误”或其他无关错误。

网络中断时，保留当前选择摘要和已选 ZIP 名称，允许用户重试；服务端通过幂等键防止重试产生重复任务。

## 验收标准

1. 新用户安装插件后，无需打开网页、输入服务地址或配对码即可开始。
2. 真实 Figma 选择、中文图层名、文字和图片资源可转换。
3. 空选择、错误 ZIP、超大文件、断网、服务异常和重复提交均有准确的状态与恢复路径。
4. 下载的 ZIP 可解压，且可被目标 FairyGUI 版本打开。
5. 产物包含变更摘要与检查结果，并且不修改原上传 ZIP。
6. 转换与下载流程在 Figma 桌面端中完成，不依赖 Windows 本地 Agent。

## 测试策略

- 插件单元测试：选择序列化、文件校验、状态转换、重复提交与错误文案。
- API 单元测试：来源限制、ZIP 安全、转换任务、产物下载和临时数据清理。
- 集成测试：使用真实工程 fixture 跑通“Figma 选择 + ZIP 上传 + 转换 + 下载”。
- 真实环境验收：在 Figma 桌面端安装交付包，完成一次正常转换和一次断网重试，并用 FairyGUI 打开下载产物。
